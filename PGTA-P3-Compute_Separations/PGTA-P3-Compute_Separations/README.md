# PGTA-P3

CALCULO DE SEPARACION

Mediante los planes de vuelo genera una parejas de vuelos que salen en la misma pista y consecutivos (un lider y un seguidor).

La clase SeparationSample muestra la separacion entre los dos vuelos en 1 instante.
La clase FlightPairSeparation muestra la separacion entre un lider y un seguidor. La separacion esta almacenada en una lista de samples.
